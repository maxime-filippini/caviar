# caviar

Basic implementation of CAViaR computations and optimization, along with 
scripts for comparison with Filtered Historical Simulations estimates.

## Repository overview

```
.
├── notebooks                   Jupyter notebooks used to produce charts and tables
│                               based on the VaR calculations
│
├── scripts                     Scripts used to run data preparation, optimization
│                               and VaR calculations
│
└── src
    └── caviar                  The library implementation
```
